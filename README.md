## Purpose
An interactive D3 data story about hospitalised injuries from road crashes in Australia
(BITRE data, 2011-2021).

## Folder structure
- index.html - main page
- css/ - stylesheets
- js/ - D3 code
- data/ - processed data files 
- assets/ - images and icons

## Team workflow
